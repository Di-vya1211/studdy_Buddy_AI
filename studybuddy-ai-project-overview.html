Study Buddy AI

An AI-powered personal study assistant combining Retrieval-Augmented Generation (RAG), local ONNX embeddings, streaming LLM responses, a Streamlit frontend, and a modern Next.js interface — designed to make studying smarter, faster, and more personalised for every student.

Document Upload
PDF, DOCX, TXT, MD, PPT, PPTX, XLSX, PNG, JPG, GIF, WEBP — parsed, chunked, indexed into FAISS + ChromaDB
📝
Paste Text
Paste notes or a topic directly — all AI tools work from raw text without any file upload
💡
ELI10 Explain
Three explanation levels (ELI5 · Beginner · Intermediate) with live streaming, analogies, and key points
🎯
Kahoot-Style Quiz
Timed MCQs with live scoring, streaks, hints, difficulty levels, and instant answer review
📅
Smart Revision Planner
Day-by-day schedule with concept, quiz, buffer, and rest sessions using spaced repetition
🤖
RAG Doubt Solver
Conversational Q&A grounded in uploaded documents with source citations — streaming SSE
🧠
Feynman Mode
AI scores your explanation 0–100, finds knowledge gaps, generates Q&A pairs and coaching tips
🃏
AI Flashcards
Generates flip-card decks from notes; "Know it / Review it" spaced-repetition loop; saved to DB
🗺️
Concept Map
One-click interactive node-edge concept map generated from any uploaded document
✨
AI Cheat Sheet
Streams a condensed cheat sheet live — printable as PDF from the browser

GIF Avatar Upload

Security Headers

Structured JSON Logging
Every request logged as JSON with latency_ms, request_id; slow-request alerts at 5 s; Sentry-ready
🎨
Animated UI
Splash screen, staggered fade-up cards, count-up numbers, confetti on quiz score ≥ 70%

⚠️ Known Limitations

⚙️
Single worker — FAISS indexes are in-process. The Dockerfile enforces --workers 1. FAISS resets on restart; re-upload documents after a Render redeploy.
💾
Streamlit Cloud data reset — The data/ directory (SQLite, uploads, vector indexes) is ephemeral and resets on redeploy. Connect a PostgreSQL DATABASE_URL for persistence.
😴
Free tier cold start — Render free tier sleeps after 15 min. First request after sleep takes 30–60 s. Subsequent requests are fast.
📦
File size limits — 20 MB per AI document upload; 50 MB for assignment / note attachments; 5 MB for avatar — all configurable via env vars.
